# TP5 - Club

## 2.1 - Structure

- Header avec navigation
- Section Hero avec titre Bienvenue au Club
- Section Inscription avec formulaire
- Footer

## 2.2 - Flexbox

- Header en flex : logo à gauche, nav à droite
- justify-content: space-between
- align-items: center

## 2.3 - Box Model de .formulaire

- Padding : 24px (1.5rem)
- Border : 1px solid #d8e0ea
- Margin : 0 auto
- Max-width : 600px
- box-sizing : border-box

Avec border-box, padding + border sont inclus dans la largeur, donc le formulaire ne déborde pas.

## 2.4 - Responsive

- Sur mobile, le formulaire prend toute la largeur
- Les champs passent en colonne
